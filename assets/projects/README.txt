PROJECT IMAGES
==============
Replace the SVG files in this folder with your own project images.
Recommended format: JPG or PNG, roughly 16:9 (for example 1200x675).

Current slots:
  sia.svg
  gaia.svg
  uhp-detection.svg
  diff-mobo.svg
  race-bias-free-face-aging.svg

You can either:
1. Keep the same filenames and replace each file, or
2. Put your own image elsewhere in assets/ and update the corresponding
   src="..." path in projects.html.

PROJECT LINKS
=============
Open projects.html and find each project-footer. Replace:
  https://github.com/
with the real GitHub / paper / demo URL for that project.

PROFILE IMAGE
=============
The home page currently uses:
  assets/profile-placeholder.svg
Replace it with your own image and update the src path in index.html.
